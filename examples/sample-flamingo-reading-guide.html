Jean-Baptiste Alayrac et al. · NeurIPS 2022

Flamingo: a Visual Language Model for Few-Shot Learning

This reading guide explains how Flamingo connects a frozen vision encoder to a frozen language model through a 64-token resampler and zero-initialized gated cross-attention. It follows one interleaved prompt through the system and marks which results are author-reported.

Attention is a controlled read

This guide assumes you know that a transformer represents text as tokens and that self-attention lets one text token read other text tokens. Cross-attention lets a text token read a separate set of tokens, here visual ones. [Section 2]

Flamingo does not train one giant model from scratch. It learns a narrow visual interface around two pretrained systems. [Abstract]

Compress every image to sixty-four notes

A vision encoder produces a variable number of spatial and temporal features, so feeding them all into every language layer would make the interface grow with resolution and video length. The Perceiver Resampler instead owns 64 learned queries. They cross-attend to the encoder features and return exactly 64 visual tokens per image or clip. [Section 2.1]

The 64 tokens are learned summaries, not 64 named objects. A fixed budget keeps cost predictable; it is also a bottleneck. That second point is my reading, not a measured result.

Gates start closed, so training starts from the language model you already have

Gated cross-attention blocks are interleaved between the frozen language layers. Each multiplies its output by tanh of a learned gate that is initialized to zero, so at the start the combined model behaves exactly like the original language model. [Section 2.2]

y = x + tanh(α) · CrossAttn(x, v)

Gate αtanh(α)Effect
0 (start)0Output equals x: vision is ignored
1≈ 0.76About three quarters of the visual signal is added

Each text token attends directly only to the visual tokens of the single image immediately before it. Earlier images reach it indirectly through the language model's self-attention. [Section 2.3]

Because the gate opens gradually, the visual pathway can be learned without first damaging what the language model already knows.

The objective is a weighted sum of per-dataset losses. [Sections 2.4–2.5] The frozen language models are Chinchilla variants, giving the 3B, 9B and 80B Flamingo sizes. [Chinchilla]

The few-shot headline is strong but author-reported

The paper evaluates 16 image and video tasks. With 32 examples in the prompt and no weight updates, Flamingo is reported to beat fine-tuned state of the art on six of them. [Section 3.1]

A prompt with a few examples replaced fine-tuning on thousands of times more task data, according to the authors. [Abstract]

What this does not show

The 64-token bottleneck is not quantified here, so how much visual detail it loses is open. The few-shot comparisons are chosen and reported by the authors, so check which baselines and tasks they cover. The paper's video clips are short, which does not establish long-video understanding.
